## 1. Purpose & Overview

This node documents the root [`.agyrules`](file:///C:/Aevum/.agyrules) configuration governing AI coding assistants (such as Antigravity) working within the [[Photo Aevum Studio]] workspace.

It establishes:
* **Read/Write Execution Phases**: Mandatory architectural review of [[Project-State]] before code changes, and chronological dev logging in `Logs/Dev-Log-YYYY-WeekXX.md` upon completion.
* **Graph Linking Directive**: Strict use of Obsidian wikilinks `[[ ]]` across components, services, database tables, and architecture concepts, with persistent backlinks to [[Project-State]].
* **Strict Clarification First Protocol**: Halting to clarify ambiguous or incomplete requirements before generating code or modifying architecture.
* **SQL Single Source of Truth Directive**: Preserving schema integrity across the three canonical SQL files: `PhotoAevumStudio.sql`, `PhotoAevumStudioIdempotent.sql`, and `PhotoAevumStudioStoredProcedures.sql`.
